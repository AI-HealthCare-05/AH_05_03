# 시나리오 03: 모바일 뷰포트(519px) 반응형 레이아웃 & 텍스트 잘림 감사

```gherkin
Feature: 모바일 해상도(519px)에서의 레이아웃 안정성, 텍스트 오버플로우 및 터치 타깃 감사

  Scenario: 모바일 뷰포트 크기로 변경했을 때 가로 스크롤 깨짐이나 텍스트 잘림이 없는지 확인한다
    Given 사용자가 브라우저 창 너비를 519px, 높이를 900px 로 리사이즈한다
    And "http://127.0.0.1/" 홈 화면으로 이동한다

    # 1. 가로 스크롤 및 오버플로우 검증
    Then 페이지 전체에 불필요한 가로 스크롤바(Horizontal Scroll)가 생기지 않아야 한다
    And 컨테이너 박스 바깥으로 텍스트나 카드가 삐져나가는 시각적 결함이 없어야 한다

    # 2. 패밀리 프로필 및 메트릭 카드 텍스트 검증
    Then 상단 가족 프로필 선택기(Family Header)의 이름과 상태 배지가 적절하게 줄바꿈되거나 정돈되어야 한다
    And 핵심 건강 지표 수치가 텍스트 박스 안에서 말줄임("...")으로 핵심 정보가 가려지지 않고 정상 표시되어야 한다

    # 3. 터치 타깃 면적 감사
    Then 주요 버튼(플로팅 챗봇 런처, 프로필 전환 칩, 네비게이션 아이콘)의 크기가 최소 44x44px 이상을 유지해야 한다

    # 4. 콘솔 및 소프트 에러 검증
    Then 리사이징 및 렌더링 과정에서 레이아웃 관련 JS 경고나 에러가 0건이어야 한다

    # 5. 최종 증적 수집
    Then 519px 모바일 뷰포트 화면의 상단 및 하단 스크린샷을 캡처한다
```
