# 1부. 최소 입력

## 1-1. 전제

모델은 어떤 항목도 **요구하지 않습니다.** 결측은 중앙값 대치 + 지시자로 처리되므로 입력이 비어도 예측은 나옵니다. 문제는 "몇 개를 받아야 쓸 만한가"입니다. 그래서 변수를 하나씩 늘리며 홀드아웃 AUROC가 어디서 포화되는지 측정했습니다.

## 1-2. 기여도 순 (전진 선택)

**당뇨 유병**

| 순서 | 추가 항목 | 누적 AUROC | 증가분 | 60+ |
|---:|---|---:|---:|---:|
| 1 | **주관적 건강** (1–5) | 0.728 | +0.228 | 0.683 |
| 2 | **나이** | 0.769 | +0.041 | 0.689 |
| 3 | **BMI** (키·몸무게) | 0.797 | +0.027 | 0.711 |
| 4 | **성별** | 0.798 | +0.002 | 0.716 |
| 5~23 | 나머지 19개 전부 | 0.802 | +0.004 | 0.733 |

**고혈압 유병**

## 1-3. 답 — 4개면 됩니다

| | 필수 | 문항 수 |
|---|---|---:|
| **최소 구성** | 나이 · 성별 · 키·몸무게(BMI) · 주관적 건강 | **4** |
| 달성 성능 | 당뇨 0.798 / 고혈압 0.777 | |
| 전체 변수 대비 | 당뇨 99.5% / 고혈압 99.7% | |

나머지 19개를 전부 받아도 **당뇨 +0.004, 고혈압 +0.002**입니다.

`주관적 건강`은 "전반적으로 본인의 건강이 어떻다고 생각하십니까 — 매우 좋음 / 좋음 / 보통 / 나쁨 / 매우 나쁨" 한 문항입니다. NHANES `HUQ010`과 BRFSS `GenHlth`가 같은 척도라 통합이 가능했고, **단일 문항 중 가장 강력합니다.**

# 2부. 무엇을 바꾸면 위험도가 내려가는가

## 2-1. 방법

홀드아웃 전원에게 현실적인 개입을 적용하고 다시 채점해, 예측 확률의 평균 변화와 "상위 10% 경보에서 벗어난 비율"을 측정했습니다.

**이건 인과 효과가 아니라 모델 반사실입니다.** 단면조사에서 학습한 연관이라, "BMI가 낮은 사람은 예측 위험이 낮다"와 "체중을 줄이면 위험이 낮아진다"는 다른 주장입니다. 대조군도 추적도 없습니다.

## 2-4. 반드시 짚어야 할 것 — 부호가 뒤집힌 항목

**당뇨 모델은 금연하면 위험이 4%p 오른다고 말합니다.** 음주를 줄이면 2.5%p, 채소·과일을 먹으면 0.6%p 오릅니다.

이건 모델의 오류가 아니라 단면 데이터의 성질입니다.

- **금연** — 단면 자료에서 현재 흡연자는 당뇨 유병률이 오히려 낮습니다. 흡연이 체중을 억제하고, 당뇨 진단을 받은 뒤에 금연하는 사람이 많아 "과거 흡연자"에 환자가 몰립니다(역인과)
- **음주** — 이른바 sick quitter 효과입니다. 병이 생겨 술을 끊은 사람이 비음주자에 섞여 있습니다
- **채소·과일** — 관리 중인 환자가 식단을 챙깁니다

**이 모델을 챌린지 효과 시뮬레이터로 쓰면 안 됩니다.** IA의 `SCR-PRED-02` What-if 시뮬레이션 화면을 이 모델로 구현하면 "금연하면 당뇨 위험이 올라갑니다"라는 화면이 나옵니다.

## 2-5. 답

**신뢰할 수 있는 지렛대는 체중(BMI) 하나입니다.**

- 두 질환 모두 방향이 같고
- 5% → 10%로 용량-반응이 선형이며
- 효과 크기가 압도적이고 (경보 해제율 34~37%)
- 60대에서 더 큽니다 (당뇨 −4.04%p vs 20대 −1.60%p)
- 임상 근거와도 일치합니다

**고혈압에 한해** 음주 절반(−4.50%p)과 채소·과일(−2.22%p)도 방향이 맞고 임상 근거와 일치하므로 쓸 수 있습니다.

**운동·수면은 이 데이터로는 움직이지 않습니다** (±0.3%p). 건강에 좋지 않다는 뜻이 아니라, 자가보고 단면조사에서는 신호가 잡히지 않는다는 뜻입니다.

## 2-6. 제품 설계 권고

| 항목 | 권고 |
|---|---|
| 우선 관리 영역 | **체중** 단일로 고정. 고혈압 사용자에 한해 음주·식단 추가 |
| What-if 시뮬레이션 (`SCR-PRED-02`) | **모델 기반 금지.** 체중 감량만 시뮬레이션하거나, 화면 자체를 보류 |
| 챌린지 추천 근거 | 모델 SHAP이 아니라 **임상 지침** 기반으로 전환. 걸음 수·물 마시기 챌린지는 모델이 효과를 못 보여줍니다 |
| 챌린지 성과 표시 | "위험도 −N%p" 대신 **실측 변화**(체중·혈압)를 보여주고, 재측정 후 재예측한 값만 %p로 표시 |
| 생활습관 문항 | 예측 기여는 0이지만 **챌린지 개인화·성과 추적에 필요**하므로 유지. 다만 온보딩이 아니라 챌린지 시작 시점으로 옮기는 것을 검토 |

## 2-7. 남는 긴장

참여기업 필수 3(생활습관 챌린지)과 필수 1(예측 모델)을 잇는 고리가 **체중 하나**뿐입니다. 걸음 수·물 마시기 챌린지를 만들어도 이 모델은 그 효과를 위험도 변화로 보여주지 못합니다.

두 갈래 중 하나를 골라야 합니다.

1. **체중 중심 서사** — 챌린지를 체중 감량으로 수렴시키고, 위험도 변화를 정직하게 연결
2. **분리 서사** — 챌린지는 임상 지침 기반으로 자유롭게 구성하고, 위험도 재계산은 재측정값(체중·혈압)으로만 수행. 모델은 "지금 상태 평가"에만 쓰고 "행동의 효과 예측"에는 쓰지 않음

**2번을 권합니다.** 정직하고, 구현이 단순하고, 부호가 뒤집힌 화면이 나올 위험이 없습니다.
