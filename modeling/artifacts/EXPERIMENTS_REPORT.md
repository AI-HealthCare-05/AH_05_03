## 1. 60대 이상 변별력 — 모델링으로는 못 고칩니다

전역 모델 / 나이 상호작용항 / 연령대 전용 모델 셋을 같은 홀드아웃에서 비교했습니다 (로지스틱 기준).

| 타깃 | 연령대 | n | 양성률 | 전역 | 상호작용 | 전용 |
|---|---|---:|---:|---:|---:|---:|
| 미진단 당뇨 | 19–39 | 1,344 | 1.3% | 0.801 | 0.790 | 0.835 |
| | 40–59 | 1,200 | 3.5% | 0.785 | 0.780 | 0.788 |
| | **60+** | 1,743 | 5.2% | **0.695** | 0.702 | 0.691 |
| 당뇨 전단계 | 19–39 | 1,249 | 23.1% | 0.648 | 0.649 | 0.648 |
| | 40–59 | 1,165 | 42.4% | 0.631 | 0.632 | 0.619 |
| | **60+** | 1,684 | 53.1% | **0.576** | 0.570 | 0.574 |
| 미진단 고혈압 | 19–39 | 1,258 | 3.8% | 0.755 | 0.768 | 0.750 |
| | 40–59 | 928 | 9.1% | 0.621 | 0.612 | 0.620 |
| | **60+** | 1,041 | 17.9% | **0.573** | 0.581 | 0.588 |

**결론.** 상호작용항도, 연령대 전용 모델도 의미 있는 개선을 주지 못합니다. 세 방법의 차이는 ±0.015 이내로 노이즈 범위입니다.

즉 60대 이상의 낮은 변별력은 **모델 선택 문제가 아니라 정보의 한계**입니다. 우리가 가진 변수(나이·성별·BMI·허리둘레·생활습관)로는 고령층 내부를 가르지 못합니다. 나이가 주 신호인데 60대 이상 안에서는 나이 분산이 작아 신호가 사라지기 때문입니다.

부수적으로, 베이스라인에서 보고한 60+ 수치(XGB 기준 0.654/0.541/0.563)보다 로지스틱이 낫습니다(0.695/0.576/0.573). 격차 일부는 XGBoost의 과적합 탓이었습니다.

**대응은 제품 쪽입니다.**
- `SCR-PRED-05`(결과 제한 안내)를 60대 이상에 적용하거나
- 해당 구간에서는 확률 대신 "재측정 권고"로 표현을 바꾸거나
- 검사값(HbA1c)을 받은 경우에만 결과를 제공

**주 사용자층이 30~60대**(`DESIGN.md` 페르소나 5명 중 54세·61세 포함)라는 점에서 이건 회피할 수 없는 결정입니다.

## 2 + 3. 보정과 운영점

### 확률은 그대로 화면에 쓸 만합니다

| 타깃 | 기저율 | Brier | ECE | 보정 기울기 | 절편 |
|---|---:|---:|---:|---:|---:|
| 미진단 당뇨 | 3.50% | 0.0327 | 0.0074 | 1.08 | +0.00 |
| 당뇨 전단계 | 40.92% | 0.2196 | 0.0305 | 0.90 | −0.13 |
| 미진단 고혈압 | 9.85% | 0.0873 | 0.0309 | **0.74** | **−0.72** |

당뇨는 거의 완벽하게 보정돼 있습니다(기울기 1.08, ECE 0.007). 고혈압은 기울기 0.74로 **예측이 과하게 극단적**입니다 — 신뢰도 곡선 최상위 분위에서 예측 0.316인데 실제는 0.204입니다. 즉 위험을 부풀려 말합니다.

Isotonic 재보정을 학습 주기 out-of-fold로 적합해 적용해도 Brier는 0.0873 → 0.0863으로 거의 안 움직입니다. **재보정보다 상위 구간 과대예측을 표현으로 눌러야 합니다** — 고혈압 결과 문구에서 확률 수치를 크게 띄우지 않는 쪽이 안전합니다.

### 운영점 — 상위 몇 %를 알릴 것인가

| 타깃 | 상위 % | 임계값 | 민감도 | 특이도 | PPV | lift |
|---|---:|---:|---:|---:|---:|---:|
| 미진단 당뇨 | 5% | 0.120 | 21.3% | 95.6% | **14.9%** | **4.25** |
| | 10% | 0.093 | 30.7% | 90.7% | 10.7% | 3.06 |
| | 20% | 0.065 | 52.0% | 81.1% | 9.1% | 2.60 |
| 미진단 고혈압 | 5% | 0.358 | 11.6% | 95.7% | 22.8% | 2.32 |
| | **10%** | 0.300 | 23.9% | 91.5% | **23.5%** | **2.39** |
| | 20% | 0.220 | 41.5% | 82.3% | 20.4% | 2.07 |
| 당뇨 전단계 | 5% | 0.693 | 7.5% | 96.7% | 61.5% | 1.50 |
| | 20% | 0.594 | 28.7% | 86.0% | 58.8% | 1.44 |

**권고 운영점**
- 미진단 당뇨: **상위 10%**. PPV 10.7%로 열 명 중 한 명이 실제 기준 초과. 상위 5%는 PPV가 14.9%로 더 높지만 민감도 21%라 대부분을 놓칩니다
- 미진단 고혈압: **상위 10%**. PPV 23.5%로 네 명 중 한 명. lift도 이 지점에서 최대
- 어느 쪽이든 "당신은 고혈압입니다"가 아니라 **"재측정과 검진을 권합니다"** 수준의 문구여야 합니다. PPV 10~24%는 확정적으로 말할 근거가 못 됩니다

### 전단계 타깃은 위험도 모델로는 값이 없습니다

상위 5%를 골라도 PPV 61.5%, lift 1.50입니다. 무작위로 골라도 40.9%가 양성이니 **모델이 더하는 값이 거의 없습니다.**

**전단계는 위험도 예측 대상에서 빼는 것을 권합니다.** 대신 검사값을 입력한 사용자에게 기준 대조로 판정해 주고(계산이면 충분합니다), 그 판정을 챌린지 진입점으로 쓰는 편이 정직하고 정확합니다.

## 4. 튜닝 — 결론이 뒤집혔습니다

| 타깃 | LR (최적 C) | XGB (최적 설정) | 차이 | 95% CI | 판정 |
|---|---:|---:|---:|---|---|
| 미진단 당뇨 | 0.773 (C=0.1) | **0.790** (depth 2, mcw 50, 200트리) | +0.017 | [−0.003, +0.037] | 구분 안 됨 |
| 당뇨 전단계 | **0.681** (C=0.01) | 0.676 (depth 2, mcw 50, 200트리) | −0.004 | [−0.010, +0.001] | 구분 안 됨 |
| 미진단 고혈압 | 0.723 (C=0.01) | **0.735** (depth 3, mcw 50, 200트리) | +0.012 | [+0.001, +0.024] | **유의** |

홀드아웃 2,000회 페어드 부트스트랩입니다.

**세 가지를 알 수 있습니다.**

1. **베이스라인의 "LR 압승"은 XGBoost 기본값 탓이었습니다.** depth 4·400트리 → depth 2~3·200트리로 바꾸니 역전됩니다. 표본 대비 모델이 컸던 겁니다
2. **그래도 차이는 작습니다.** 세 타깃 중 둘은 신뢰구간이 0을 지나가고, 유의한 하나(고혈압)도 +0.012로 실용적 의미는 크지 않습니다
3. **최적 정규화가 전부 강한 쪽입니다** (C=0.01~0.1, min_child_weight=50). 데이터가 담을 수 있는 복잡도의 상한을 보여줍니다

**권고.** 주 모델은 **로지스틱 회귀**로 갑니다. 성능이 사실상 동등하고, 계수를 그대로 기여 요인으로 쓸 수 있고, 서빙이 가볍고(P95 200ms 목표에 여유), 모델 카드에 설명하기 쉽습니다. XGBoost는 비교 대조군으로 남깁니다.

## 5a. UCI 891 외부 대조

공통 변수 5개(나이·BMI·성별·비흡연 여부·신체활동 여부)로 맞췄습니다.

| 설정 | AUROC | AUPRC | 기저율 |
|---|---:|---:|---:|
| UCI 학습 → UCI 시험 (내부) | 0.747 | 0.298 | 13.9% |
| **NHANES 학습 → UCI 시험 (전이)** | **0.735** | 0.282 | 13.9% |
| NHANES 학습 → NHANES (참고) | 0.761 | 0.744 | 51.9% |

**전이 손실이 0.012뿐입니다.** 253,680명 규모의 다른 조사(BRFSS 2015, 전화 자가보고)에 NHANES(검진 실측) 학습 모델을 그대로 적용해도 순위 성능이 거의 유지됩니다. 변수 5개짜리 축소 모델이라는 한계는 있지만, **모델이 특정 조사에 과적합되지 않았다는 증거**입니다.

다만 유병률이 51.9% vs 13.9%로 크게 다릅니다. 순위는 옮겨가도 **확률 자체는 옮겨가지 않습니다** — 다른 인구에 적용할 때 재보정이 필수입니다.

## 5b. TabPFN — 사전학습 표 모델

| 타깃 | TabPFN | 튜닝 XGB | 튜닝 LR | 학습 맥락 | 소요 |
|---|---:|---:|---:|---|---:|
| 미진단 당뇨 | 0.783 | 0.790 | 0.773 | 3,000행 (12,081 중) | 232초 |
| 당뇨 전단계 | 0.677 | 0.676 | 0.681 | 3,000행 (11,668 중) | 218초 |
| 미진단 고혈압 | 0.731 | 0.735 | 0.723 | 3,000행 (9,231 중) | 165초 |

**학습 데이터 1/4만 쓰고 튜닝 없이 튜닝된 GBDT와 동등합니다.** 표 형식 파운데이션 모델이 실제로 작동한다는 걸 확인했습니다.

**다만 제품에는 못 씁니다.**

| 제약 | 내용 |
|---|---|
| 라이선스 | 최신 버전(8.4.0)은 HuggingFace 게이트 저장소라 브라우저 로그인 또는 `TABPFN_TOKEN` 필요. **비대화형 환경에서 실행 불가** |
| 구버전 우회 | 2.1.3은 게이트가 없지만 **scikit-learn을 1.6.1로 다운그레이드**시켜 나머지 파이프라인과 충돌 |
| CPU | 1,000행 초과는 기본 차단. 강제 해제해도 3,000행 맥락에 3~4분 소요 → **P95 200ms 목표와 3자릿수 차이** |
| 의존성 | torch 필요 (약 200MB) |

이 실험은 `uv sync --group ds`로 환경을 되돌려 놨습니다. 재현하려면 별도 환경이 필요합니다.

```bash
uv pip install --index-url https://download.pytorch.org/whl/cpu torch
uv pip install "tabpfn>=2.0,<2.2"
TABPFN_ALLOW_CPU_LARGE_DATASET=1 TABPFN_CONTEXT=3000 python modeling/experiments.py tabpfn
uv sync --group ds   # 환경 복구
```

**결론: 비교 실험으로는 가치가 있고(평가기준 3-1 실험 비교 소재), 서빙 모델로는 후보가 아닙니다.**
