# 여성 해부 모델 근육 이식·볼륨 보정 작업 지침

> 상태: Blender 작업 기준 문서
>
> 기준일: 2026-08-31
>
> 관련 문서: [Three.js 인체 건강 시각화 컨텍스트](17_threejs_human_body_dashboard_context.md)

## 1. 목적

남성 기준 해부 모델의 근육을 여성 골격과 외피에 이식하되, 근육의 이름·섬유 방향·기시점·정지점과 전체 비례감을 보존하면서 과도한 근복 두께를 줄인다.

최종 용도는 사실적인 운동 애니메이션보다 구조 선택과 설명을 위한 해부학 인터페이스다. 따라서 다음 순서로 품질을 판단한다.

1. 올바른 뼈에 부착되어 있는가.
2. 근육의 진행 방향과 좌우 대응이 해부학적으로 읽히는가.
3. 근육이 여성 외피 안에 안정적으로 들어가는가.
4. 인접 근육을 구분할 수 있는가.
5. 관절 운동 시 완벽하게 변형되는가.

5번은 향후 필요할 때 보강한다. 이를 위해 원본 구조와 작업 기록은 보존하지만, 현재 일정에서는 완벽한 관절 애니메이션 때문에 골격·외피 배치를 다시 흔들지 않는다.

## 2. 기본 해부 원칙

- 여성과 남성에게 서로 다른 종류의 골격근이 존재한다고 가정하지 않는다.
- 동일 근육의 기시점·정지점, 진행 방향과 기능을 먼저 보존한다.
- 성별만으로 일률적인 축소율을 적용하지 않는다. 현재 여성 외피, 골격 비율과 목표 체형이 최종 기준이다.
- 유방은 대흉근이 아니라 그 위에 놓이는 유선·지방 조직이다.
- 자궁은 골반 내부 장기이며 외형 근육 보정과 별도로 배치한다.
- 근육의 선명도를 줄이기 위해 근육 형상을 무조건 납작하게 만들지 않는다. 현재 여성 외피 안에서의 정합과 부위별 근복 보정으로 판단한다.
- 남성 원본에 없는 근막면·피하지방 등의 신규 표시 레이어는 이번 작업 범위에 추가하지 않는다. 구조와 토글이 복잡해지는 것을 피하고 생략한다.
- 힘줄은 근복보다 훨씬 가늘어도 정상이다. 손가락과 발가락으로 이어지는 굽힘·폄힘줄을 근육 돌출로 오인해 제거하지 않는다.

## 3. 절대 보존 항목

다음 항목은 별도 승인 없이 변경하지 않는다.

- 완성된 여성 골격의 월드 배치
- 외피의 위치·회전·스케일과 형상
- 근육의 양 끝 부착점 주변 형상
- 힘줄과 건막의 진행 경로
- 좌우 구조의 해부학적 대응 관계
- 원본 남성 근육 오브젝트
- 이미 승인된 손·손목·전완 골격 정합

근육 작업이 다시 뼈를 외피 밖으로 이동시키거나 외피를 크게 수정해야만 성립한다면 해당 실험을 중단한다.

## 4. 비례를 유지하는 근복 축소 방식

### 4.1 전체 오브젝트 스케일을 사용하지 않는 이유

근육 전체를 균일 축소하면 기시점과 정지점이 뼈에서 떨어진다. 한 축만 축소하면 섬유 방향과 부착면이 왜곡된다. 따라서 기본 보정은 근육의 길이를 고정하고 중앙 근복의 단면만 줄이는 방식으로 한다.

### 4.2 로컬 중심선 기반 방사형 축소

각 근육에 대해 다음 절차를 사용한다.

1. 근육의 긴 방향을 로컬 중심선으로 정한다.
2. 중심선 위의 위치를 `t = 0..1`로 정규화한다.
3. 양 끝 부착 구간은 원래 크기를 유지한다.
4. 중앙으로 갈수록 방사형 축소량을 부드럽게 증가시킨다.
5. 길이 방향 좌표는 기본적으로 변경하지 않는다.

개념식은 다음과 같다.

```text
radialScale(t) = 1 - (1 - middleScale) * sin(pi * t)^power
```

- `middleScale`: 근복 중앙의 방사형 스케일
- `power`: 부착점에서 중앙부로 넘어가는 완급
- `t=0`, `t=1`: 스케일 1로 부착점 보존
- `t=0.5`: 가장 큰 축소 적용

근육 길이가 실제 여성 뼈의 두 부착점과 맞지 않을 때만 길이 방향을 별도로 보정한다. 이 경우에도 먼저 양 끝점을 여성 뼈 랜드마크에 고정하고 중간 정점만 재분포한다.

### 4.3 파일 용량 관리

- 초기 배치와 비교 단계에서는 원본 mesh data를 공유한 linked copy를 사용한다.
- 실제 정점 변형이 필요한 오브젝트만 승인 직전에 single-user mesh로 전환한다.
- 실패한 실험 메쉬와 중복 컬렉션은 현재 실험 파일에서만 정리한다.
- 사용자가 요청하지 않으면 새 `.blend` 파일을 계속 만들지 않는다.

## 5. 부위별 보수적 시작 프로필

아래 값은 생물학적 성별 표준이 아니라 현재 모델에서 외피 침범을 줄이기 위한 **시각적 시작값**이다. 방사형 스케일이며, 적용 후 반드시 외피와 뼈를 기준으로 다시 판단한다.

| 부위 | 중앙 근복 시작 범위 | 주의사항 |
| --- | ---: | --- |
| 승모근·광배근 | 0.88–0.94 | 견갑극·쇄골·상완골 부착부 고정 |
| 대흉근 | 0.88–0.94 | 유방 볼륨을 대흉근으로 만들지 않음 |
| 삼각근·상완 근육 | 0.90–0.95 | 견관절과 팔꿈치 부착부 유지 |
| 전완 근육 | 0.91–0.96 | 손목으로 이어지는 힘줄은 축소 대상에서 제외 |
| 복직근·외복사근 | 0.91–0.97 | 골반·갈비뼈 경계를 먼저 맞춤 |
| 손·발 내재근 | 0.95–1.00 | 매우 작으므로 자동 축소를 최소화 |
| 둔부·골반저 | 자동 축소 금지 | 여성 골반에 맞춰 별도 재배치 |
| 허벅지·종아리 | 0.91–0.97 | 무조건 가늘게 만들지 말고 외피 단면 우선 |

한 번에 목표값까지 줄이지 않고 `1차 50% → 확인 → 나머지 50%`의 두 단계로 적용한다.

### 5.1 완성도 부족 시 사용할 비교 비율 후보

아래 값은 현재 모델에 즉시 적용하는 기본값이 아니다. 전체 근육 배치가 끝난 뒤에도 남성형 근육량이 과도하게 느껴질 때만 별도 실험본에서 비교하는 **후보값**으로 기록한다. 개인 체격·운동 상태와 근육별 차이가 크므로 성별의 절대 표준으로 취급하지 않는다.

| 비교 부위 | 남성 원본 대비 단면적 후보 | 단면의 두 축을 함께 줄일 때의 방사형 스케일 |
| --- | ---: | ---: |
| 상체 큰 근육군 | 0.50–0.60 | 약 0.71–0.77 (`sqrt(면적비)`) |
| 하체 큰 근육군 | 0.70–0.75 | 약 0.84–0.87 (`sqrt(면적비)`) |
| 둔근 | 일괄 축소 보류 | 골반·체중·외피에 맞춰 개별 판단 |

적용 판단 규칙:

- 현재 승인된 위치·길이·기시점·정지점은 유지한다.
- 앞뒤 한 축만 줄이는 경우에는 `sqrt(면적비)`를 사용하지 않는다. 한 축 스케일과 단면적 변화가 거의 직접 대응한다.
- 위 목표값을 한 번에 적용하지 않고 현재 값과 후보값 사이의 절반만 먼저 적용한다.
- 외피 침범이나 남성형 근복 과장이 명확하지 않으면 적용하지 않는다.
- 적용 전후를 같은 카메라와 같은 표시 상태에서 비교한 뒤 더 나은 쪽만 남긴다.

## 7. 검증 체크리스트

각 부위 완료 전에 다음을 확인한다.

- [ ] 기시점과 정지점이 대응 뼈에서 이탈하지 않았다.
- [ ] 근복만 줄었고 힘줄은 연속성을 유지한다.
- [ ] 근육이 뼈를 비정상적으로 관통하지 않는다.
- [ ] 외피 밖으로 넓게 돌출된 부분이 없다.
- [ ] 정면·후면·좌측·우측·상면·하면에서 확인했다.
- [ ] 좌우가 이름과 위치 모두 대응한다.
- [ ] 손가락·발가락의 가는 줄기를 무조건 오류로 제거하지 않았다.
- [ ] 컨트롤러 표시와 실제 해부 메쉬를 구분했다.
- [ ] 원본 남성 근육과 여성 작업본을 서로 다른 컬렉션으로 유지한다.
- [ ] 현재 실험 파일 하나에 저장했으며 불필요한 새 파일을 만들지 않았다.

## 8. 중단·복구 기준

다음 중 하나가 발생하면 해당 자동 보정을 되돌리고 수동 미세 조정 또는 다음 작업으로 넘어간다.

- 근육 보정을 위해 골격을 다시 외피 밖으로 꺼내야 한다.
- 관절 정합을 다시 대규모로 수정해야 한다.
- 부착점 다수가 뼈에서 분리된다.
- 한 부위 보정이 반대편이나 손·발 정합을 연쇄적으로 망가뜨린다.
- 외피 침범을 없애려면 근육의 해부학적 형태를 알아보기 어렵게 해야 한다.
- 자동화 수정 범위가 현재 일정에 비해 지나치게 커진다.

이 경우 실패한 실험만 버리고 승인된 골격·외피 상태를 유지한다. 신규 근막·피하지방 표시 레이어는 만들지 않으며, 필요하면 남성 원본에 존재하는 다음 근육군 또는 별도 여성 장기 단계로 진행한다.

## 9. 현재 Blender 기준 상태

작업 파일:

```text
/Users/fabxoe/Downloads/first-good-left-hand-anatomy-female-fit-work-v34-explicit-navicular-anatomy-interface-exp.blend
```

연결 구분:

```text
BlenderMCP: 9876
MCP: 19876
```

Blender 재시작 후 연결 판정 규칙:

- `BlenderMCP` 패널의 `Disconnect from MCP server` 문구만으로 정상 연결을 판정하지 않는다.
- 재시작 직후에는 버튼이 `Disconnect...`로 보여도 `9876`의 소켓 또는 Blender 메인 스레드 명령 처리가 멈춘 반쪽 상태일 수 있다.
- 먼저 `9876`에 읽기 전용 `ping`을 보내 실제 응답을 확인한다.
- 응답이 없으면 Blender에서 `BlenderMCP` 버튼을 한 번 눌러 `Connect...` 상태로 끈 다음, 다시 눌러 `Disconnect...` 상태로 재시작한다.
- 재시작 후 `ping`과 읽기 전용 Blender 명령이 모두 응답해야 정상으로 간주한다.
- 공식 `MCP: 19876`은 별도 서버이므로 `BlenderMCP: 9876`과 혼동하지 않는다.

현재 생성 단계:

- `FEMALE_UPPER_LIMB_MUSCLE_V1`: 상지 근육 101개
- `FEMALE_TRUNK_MUSCLE_V1`: 몸통 표층 근육 27개
  - 가슴 8개
  - 등 12개
  - 복부 7개
- 몸통 정합 기준: 경추·흉추 대응점 기반 similarity fit
- 몸통 정합 결과: scale 약 `0.994`, RMS 약 `7.6mm`
- 정면·후면 확인: 큰 외피 이탈 없이 좌우 흐름 유지
- `FEMALE_VOLUME_V2`: 큰 근육 55개에 중심부 볼륨 보정 완료
  - 어깨·상완 29개, 가슴 8개, 등 12개: 중앙 방사형 누적 스케일 `0.9409`
  - 복부 6개: 중앙 방사형 누적 스케일 `0.9604`
  - 양 끝 부착부와 길이 방향 좌표는 유지
  - 전완·손·힘줄·근막·인대·백선은 자동 축소에서 제외
  - 정면·후면·좌우측·상면·하면 6방향 검사에서 넓은 외피 이탈이나 부착 분리 없음
- `FEMALE_PELVIS_MUSCLE_V1`: 골반 표층 근육 8개 1차 배치
  - 대둔근·중둔근·소둔근·대퇴근막장근 좌우 각 1개
  - 남성 골반·대퇴골 중심과 여성 골반·대퇴골 중심을 대응한 `pelvis_femur_landmark_blend_v1` 정합
  - 여성 골반의 좌우 폭과 높이, 대퇴골두 위치를 반영하고 좌우 대칭 유지
- `FEMALE_PELVIS_VOLUME_V1`: 골반 표층 근육 앞뒤 두께 보정 완료
  - 대둔근 `0.95`, 중둔근 `0.97`, 소둔근 `0.985`, 대퇴근막장근 `0.98`

### 왼손 신전근 힘줄 소단계 기록 (Extensor digitorum)

- 작업 대상: `FEMALE_MUSCLE_L_Extensor digitorum.l`
- 네 갈래를 손목 쪽에서 고정하고 손끝 방향으로 점진 감쇠하여 보정했다.
- 바깥쪽 첫 갈래는 누적 2 mm, 안쪽 두 번째 갈래는 1 mm, 반대쪽 끝 갈래는 누적 2 mm 안쪽 보정을 적용했다.

- 피부 최근접 거리값은 손가락 사이에서 반대편 피부 면을 선택할 수 있으므로 수치만으로 큰 이동을 하지 않는다. 이후에도 한 번에 최대 1 mm씩 이동하고 3방향 시각 검증을 우선한다.
