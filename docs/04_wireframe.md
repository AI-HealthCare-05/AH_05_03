# 와이어프레임 가이드

> 담당: 정다원(주도)
> 관련 평가기준: 1-3, 4-1(3~5단계 접근), 4-2(일관된 UX), 4-3(3~5회 액션 접근)
> 실제 와이어프레임은 Figma로 제작(Mid-Fi부터 시작 권장)하고, 완성 후 이 문서 하단에 링크를 추가한다. 이 문서는 화면 목록과 흐름을 먼저 텍스트로 합의하기 위한 것이다.

## 1. 디자인 시스템 원칙 (평가기준 4-2)

- 컴포넌트: Shadcn/ui 기반, Tailwind CSS 유틸리티로 스타일링.
- 공통 토큰: 브랜드 컬러 1(주조색) + 보조색 1~2, 타이포그래피 스케일(H1~H3, Body, Caption) 통일.
- 모든 화면에서 동일한 상단/하단 내비게이션 구조 유지 → 화면마다 레이아웃이 달라지지 않도록 함.

## 2. 화면 목록 및 접근 흐름 (평가기준 4-1, 4-3)

핵심 내비게이션은 4개 탭(홈/대시보드/챌린지/마이)으로 고정하여 어떤 화면에서도 2탭 이내에 도달 가능하게 한다.

| 화면 | 목적 | 진입 경로(depth) | 관련 REQ |
|---|---|---|---|
| 온보딩/로그인 | 회원가입, 로그인 | depth 1 (앱 진입 시) | REQ-01 |
| 최초 건강정보 입력 | 예측을 위한 최소 정보 입력(수동 또는 OCR) | 로그인 → depth 2 | REQ-02, REQ-07 |
| 홈 | 오늘의 요약(예측 확률, 추천행동, 챌린지 진행률) | 탭 → depth 1 | REQ-03, REQ-05 |
| 대시보드 | 건강데이터·예측 확률 추이 그래프 | 탭 → depth 1 | REQ-03 |
| 건강데이터 입력 | 수동/OCR 입력 폼 | 홈 → 입력 버튼 → depth 2 | REQ-02, REQ-07 |
| 챌린지 목록 | 참여 가능한 챌린지 리스트 | 탭 → depth 1 | REQ-04 |
| 챌린지 상세/체크인 | 목표, 진행률, 오늘 인증 | 목록 → 카드 클릭 → depth 2 | REQ-04 |
| 마이페이지 | 프로필, 피드백 내역, 알림 설정 | 탭 → depth 1 | REQ-06, REQ-08 |

**흐름 검증**: "예측 결과를 보고 싶다" → 앱 실행 → 홈 탭(이미 진입 시 depth 1) → 예측 카드 클릭(depth 2) = 2단계로 4-1(3~5단계 이내) 충족. "챌린지에 참여하고 싶다" → 챌린지 탭(1) → 챌린지 선택(2) → 참여하기 버튼(3) = 3단계.
