# 평가기준 대응 계획 (Evaluation Plan)

> 출처: 참여기업 평가 기준 안내 (오즈코딩스쿨 AI 헬스케어 5기 파이널 프로젝트, Talos 트랙)
> 목적: 6개 대분류 20개 세부 항목을 "우연히 충족"이 아니라 **설계 단계에서 의도적으로 충족**시키기 위한 매핑표. 각 항목은 0~5점, 공통 채점 기준(5점=정량 근거·문서·테스트 결과 명확 / 0점=미구현)이 적용된다.
>
> 평가 시점: 종료일(2026-09-21) 기준 1주일 전(2026-09-14)까지 배포 완료 → 배포 후 3일 이내 평가 → 데모데이(2026-09-22)에 결과 공개.

## 사용법

- **상태**: `계획됨` → 설계는 끝났지만 미구현 / `진행중` / `완료` / `증빙완료`(스크린샷·로그·테스트 결과까지 확보) 로 갱신한다.
- 이 표의 각 행은 뒤에 작성되는 01~05, 07 문서의 특정 섹션과 1:1로 연결된다. 표를 먼저 채우고 나머지 문서를 그 결정에 맞춰 작성한다.
