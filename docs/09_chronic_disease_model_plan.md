# 만성질환 위험 모델 실행 계획 및 평가

> 작성일: 2026-08-14  
> 상태: 베이스라인 실행 및 자체 평가 완료  
> 데이터: `hesscl/quackrfss` BRFSS 2024 Parquet

## 1. 목표

하나의 공통 전처리·학습 파이프라인으로 여러 만성질환의 보고 가능성을 각각 추정하는 Logistic Regression 베이스라인을 만들고 실제 데이터로 평가한다.

이 모델은 미래 발병이나 의학적 확진을 예측하지 않는다. BRFSS 응답자가 의료진에게 해당 질환을 진단받았다고 보고할 가능성을 추정하는 연구용 위험 모델이다.

## 2. 설계 결정

### 모델 구조

- 모델 코드를 질환마다 복제하지 않는다.
- 공통 특징 처리기와 학습 함수를 재사용한다.
- 질환별로 독립된 이진 분류기, 임계값, 평가 결과를 저장한다.
- 향후 다중 과제 모델과 비교할 수 있도록 타깃 정의를 설정 데이터로 분리한다.

### 1차 타깃

2024년 공통 핵심 문항에 있고 조건부 선택 모듈이 아닌 질환을 우선한다.

| 모델 키 | BRFSS 변수 | 의미 |
|---|---|---|
| `heart_attack` | `CVDINFR4` | 심근경색 진단 보고 |
| `coronary_heart_disease` | `CVDCRHD4` | 협심증·관상동맥질환 진단 보고 |
| `stroke` | `CVDSTRK3` | 뇌졸중 진단 보고 |
| `current_asthma` | `ASTHMA3`, `ASTHNOW` | 현재 천식 상태 |
| `skin_cancer` | `CHCSCNC1` | 피부암 진단 보고 |
| `other_cancer` | `CHCOCNC1` | 피부암 외 암 진단 보고 |
| `copd` | `CHCCOPD3` | COPD·폐기종·만성기관지염 통합 응답 |
| `depression` | `ADDEPEV3` | 우울장애 진단 보고 |
| `kidney_disease` | `CHCKDNY2` | 신장질환 진단 보고 |
| `arthritis` | `HAVARTH4` | 관절염 관련 질환 통합 응답 |
| `diabetes` | `DIABETE4` | 임신성·전당뇨를 제외한 당뇨 진단 보고 |

`모름`, `응답 거부`, `질문하지 않음`은 음성으로 바꾸지 않고 해당 타깃의 학습·평가에서 제외한다.

### 입력 특징

진단 결과나 다른 만성질환 변수를 입력으로 사용하지 않는다. 데이터 누수와 질환 간 순환 설명을 줄이기 위해 다음 기본 특성만 사용한다.

- 연령
- 성별
- BMI
- 교육 수준
- 소득 구간
- 고용 상태
- 운동 여부
- 흡연 상태
- 음주 여부

### 검증 전략

- 무작위 행 분할 대신 주(state) 단위 그룹 분할을 사용한다.
- 학습·검증·시험 데이터의 주가 겹치지 않게 한다.
- 검증 세트에서 가중 Youden J가 최대인 질환별 임계값을 선택한다.
- 최종 수치는 한 번도 임계값 선택에 사용하지 않은 시험 주에서 산출한다.
- `_LLCPWT`를 학습과 평가의 표본 가중치로 사용한다.

## 3. 평가 기준

질환별로 다음 지표를 저장한다.

- 표본 수와 가중 유병률
- AUROC
- AUPRC와 무작위 기준선인 유병률
- Brier score
- 선택 임계값
- 민감도·특이도
- 양성예측도·음성예측도
- 성별 하위집단 AUROC·민감도·특이도

베이스라인 채택 기준은 다음과 같다.

1. 실행과 재현에 실패하는 질환이 없어야 한다.
2. 모든 시험 세트에 양성과 음성이 존재해야 한다.
3. AUROC가 0.5보다 높아야 한다.
4. AUPRC가 해당 질환의 시험 유병률보다 높아야 한다.
5. 지표가 낮더라도 숨기지 않고 한계와 개선안을 기록한다.

## 6. 사전 위험 통제

- 선택 모듈의 결측을 질환 없음으로 간주하지 않는다.
- 다른 질환 진단 변수와 주관적 건강평가를 입력 특징에서 제외한다.
- 2024년 한 해의 단면 설문이므로 미래 발병 예측이라는 표현을 사용하지 않는다.
- 2011년 이전·이후 변수명을 단순히 합치지 않는다. 다년 학습은 별도 조화표를 만든 뒤 진행한다.
- 실제 서비스에서는 모델 결과를 진단이나 치료 지시로 표시하지 않는다.

## 7. 실행 결과

### 실행 조건

- 전체 BRFSS 2024 자료 사용
- 공통 전처리기 1개와 질환별 Logistic Regression 11개 학습
- 학습 33개 주·검증 9개 주·시험 11개 주로 분리
- 시험 세트는 질환별 약 12만1천 명
- 학습과 평가에 `_LLCPWT` 적용
- 임계값은 검증 주에서 선택하고 시험 주에서는 변경하지 않음

### 시험 주 평가

| 질환 | 가중 유병률 | AUROC | AUPRC | 민감도 | 특이도 | PPV |
|---|---:|---:|---:|---:|---:|---:|
| 관상동맥질환 | 4.6% | 0.825 | 0.177 | 0.776 | 0.730 | 0.123 |
| COPD 통합 | 6.4% | 0.822 | 0.300 | 0.728 | 0.767 | 0.177 |
| 심근경색 | 4.4% | 0.819 | 0.180 | 0.836 | 0.651 | 0.099 |
| 피부암 | 5.4% | 0.815 | 0.183 | 0.813 | 0.687 | 0.128 |
| 관절염 통합 | 26.8% | 0.813 | 0.587 | 0.747 | 0.738 | 0.510 |
| 뇌졸중 | 3.3% | 0.800 | 0.116 | 0.778 | 0.695 | 0.080 |
| 당뇨 | 12.3% | 0.791 | 0.326 | 0.758 | 0.687 | 0.254 |
| 피부암 외 암 | 8.2% | 0.791 | 0.220 | 0.746 | 0.702 | 0.183 |
| 신장질환 | 4.0% | 0.773 | 0.124 | 0.703 | 0.728 | 0.098 |
| 우울장애 | 20.8% | 0.700 | 0.405 | 0.593 | 0.702 | 0.343 |
| 현재 천식 | 11.0% | 0.643 | 0.203 | 0.471 | 0.738 | 0.182 |

모든 질환에서 AUROC가 0.5를 넘었고 AUPRC가 해당 시험 유병률을 넘었다. 사전에 정의한 기술적 베이스라인 기준은 모두 통과했다.

### 하위집단 확인

성별 AUROC 절대 차이가 가장 큰 질환은 다음과 같다.

- 피부암 외 암: 0.063 (`남성 0.823`, `여성 0.760`)
- 현재 천식: 0.055 (`남성 0.586`, `여성 0.642`)
- 피부암: 0.037 (`남성 0.833`, `여성 0.796`)
- 뇌졸중: 0.033 (`남성 0.817`, `여성 0.784`)

이 차이는 곧바로 차별을 증명하지 않지만 동일한 기준으로 사용자에게 위험 알림을 제공하기 전에 원인 분석과 집단별 보정이 필요하다는 신호다.

### 로컬 실행 적합성

공통 전처리기는 약 4 KB, 각 질환 모델은 약 1.2 KB다. 11개 모델과 전처리기를 합쳐도 약 17 KB로 작아서 로컬 저장과 실행에는 충분히 적합하다. 모델 크기보다 입력값 정의, 임계값 검증, 의료적 표현 통제가 더 큰 제품 위험이다.

## 8. 최종 평가와 결정

### 통과한 항목

- 한 코드 경로에서 11개 질환 모델을 재현 가능하게 생성했다.
- 질환별 결측 라벨을 음성으로 오인하지 않았다.
- 주 단위로 데이터를 분리해 같은 주의 응답자가 학습과 시험에 섞이지 않게 했다.
- 설문 가중치를 학습과 평가에 모두 반영했다.
- 모든 질환에서 무작위 수준보다 높은 순위 성능을 확인했다.
- 생성 모델을 작은 공통 전처리기와 질환별 파일로 분리해 로컬 우선 구조에 맞췄다.

### 통과하지 못한 제품 적용 조건

- 현재 천식 AUROC는 0.643이고 민감도는 0.471로 낮다.
- 우울장애 AUROC는 0.700으로 제한적이다.
- 희귀 질환의 PPV는 약 0.08~0.18에 불과하다. 사용자에게 직접 경고하면 거짓 양성이 많을 수 있다.
- 2024년 한 해, 한 번의 주 단위 분할만 평가했다.
- BRFSS의 자기보고 진단 여부를 학습했으므로 미래 발병이나 실제 미진단 질환을 검증하지 못했다.
- 성별 성능 차이가 0.05를 넘는 질환이 있다.
- 성별·소득 같은 민감 특성을 사용할지에 대한 제품 정책과 공정성 검토가 없다.

### 결정

**기술 베이스라인은 채택하지만 사용자 대상 위험 알림 모델로는 아직 채택하지 않는다.**

현재 산출물은 데이터 파이프라인 검증, 로컬 추론 구조 검증, 후속 모델 비교의 기준선으로 사용한다. 화면에는 연결하지 않고 연구용 플래그를 유지한다.
