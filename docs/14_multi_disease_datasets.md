## 0. 세 문장 요약

**팀 안에 이미 KNHANES 2024 원시자료가 들어와 있다.** `docs/HN24_chronic_disease_데이터명세서.xlsx`가 6,997행 × 31변수를 담고 있고 타깃이 고혈압·당뇨·이상지질혈증 3개다 — "국내 자료 전부 막힘"이라는 [21번](21_modeling_overview.md) §1의 기록은 낡았다. 76개 후보를 조사하고 URL·접근조건을 하나씩 열어 검증한 결과, 질환을 늘리는 데 **새 데이터가 필요 없는 항목이 5개**(이상지질혈증 일부·대사증후군·지방간·비만·신기능)이고 나머지는 NHANES 파일 세 개를 더 받으면 열린다. 더미 데이터는 성능 문제를 풀지 못한다 — 진짜 사람을 두 배 넣어도 AUROC가 0.002 움직였다는 기록이 이미 저장소 안에 있다(§4.7).

## 1. 조사 전에 뒤집힌 전제

`docs/HN24_chronic_disease_데이터명세서.xlsx`. 저장소 루트 `docs/`에 8월 10일부터 있었고, 지금까지 어느 문서도 이 파일을 언급하지 않았다.

| 시트 | 내용 |
|---|---|
| `HN24_chronic_disease_raw` | 6,997행 실데이터 |
| 데이터셋 개요 | 파일명 `HN24_chronic_disease_raw.csv`, 31컬럼, "원본 변수 + Target 추출 단계" |
| 데이터 명세서 | 변수 31개 × 역할·자료형·단위·결측률 |
| 결측 및 데이터 현황 | 변수별 결측수·고유값수 |

`HN24`는 국민건강영양조사 제9기 3차년도(2024) 원시자료의 파일 접두어다. 담긴 변수를 그대로 옮긴다.

| 분류 | 변수 | 결측률 |
|---|---|---|
| 기본 | `sex`, `age` | 0% |
| 신체계측 | `HE_ht`, `HE_wt`, `HE_wc` | 0.6~5.3% |
| 혈압 | `HE_sbp`, `HE_dbp` (2·3차 측정 평균) | 3.7% |
| 체성분 | `BIA_LRA/LLA/LRL/LLL/BFM/PBF` | 39.0% |
| 신체활동 | `BE3_71~74`, `BE3_81~84`, `BE3_91~94`, `BE3_31~33` | 0.13% |
| **타깃** | `HE_HP` 고혈압 유병여부, `DE1_dg` 당뇨 의사진단, `DI2_pr` 이상지질혈증 현재 유병 | 14.9% / 0.13% / 0.13% |

**이 자료가 바꾸는 것과 바꾸지 않는 것을 나눠야 한다.**

바꾸는 것. 한국인 실측 혈압·허리둘레·체성분이 손에 있다. 지금 서빙 모델이 미국 NHANES 단독 학습이라 안고 있는 "한국인 미보정"이라는 한계를 실제 데이터로 다룰 수 있다. 그리고 KNHANES 취득 절차를 다시 조사할 이유가 사라졌다 — 누군가 이미 통과했다.

바꾸지 않는 것. **이 추출본에는 검사값이 없다.** 공복혈당·HbA1c·지질 4종·크레아티닌이 한 컬럼도 없다. 그래서 `DE1_dg`는 "의사한테 당뇨라고 들었나"이고 `DI2_pr`는 "지금 이상지질혈증인가"라서 자가보고다. 측정 기준 라벨은 `HE_HP` 하나뿐이다. [21번](21_modeling_overview.md) §2.2가 UCI 891에서 겪은 문제 — 자가보고 라벨과 측정 라벨을 섞으면 서로 다른 타깃을 동시에 학습한다 — 가 그대로 재현될 자리다.

또 하나. 6,997행에 **4세·6세 응답자가 섞여 있다.** KNHANES 전 연령 표본이라 성인 필터가 아직 안 걸렸다.

**그래서 0번 작업은 조사가 아니라 확인이다.** 누가 언제 받았는지, `HN24_chronic_disease_raw.csv` 원본이 어디 있는지, 원시자료 전체(약 800개 변수)를 받았는데 31개만 뽑은 것인지 아니면 31개만 받은 것인지. 전체를 받았다면 검사값을 다시 추출하는 것으로 이 문서의 절반이 해결된다.

## 2. 데이터 부족이 원인인가

아니다. 세 갈래로 확인했다.

**저장소 기록.** [21번](21_modeling_overview.md) §4.7이 NHANES 4주기를 더 붙여 표본을 25,457 → 48,895명으로 늘렸고 당뇨 AUROC가 0.809 → 0.810, 고혈압이 0.797 → 0.796으로 움직였다. 소수점 셋째 자리다.

**외부 문헌.** 검사값을 전부 쓰고 한국인 20만~36만 명을 10년 추적해 만든 모형들이 어디에 있는지 보면 감각이 잡힌다.

| 모형 | 표본 | AUROC |
|---|---|---|
| KRPM (Jee 2015, Korean Heart Study) | 200,010명 | 0.741 / 0.745 |
| Korean CVD model (2014) | 57,393명 | 0.757 (추적 3.1년) |
| Korean Diabetes Risk Score (2018, NHIS-HEALS) | 359,349명 | 0.71 / 0.76 → **KoGES 외부검증 0.63 / 0.66** |
| 국가건강검진 HRA 개선 모형 | 국내 코호트 | 0.813 / 0.849 (**계수 미공개**) |
| **저장소 서빙 모델** | NHANES 48,895명 | **당뇨 0.810 / 고혈압 0.796** |

저장소 모델은 이 구간 안에 있다. 아래가 아니다.

마지막 줄을 따로 새길 만하다. Korean Diabetes Risk Score가 자기 데이터에서 0.71/0.76이었다가 KoGES 외부검증에서 0.63/0.66으로 떨어졌다. **국내 코호트끼리도 이만큼 떨어진다.** 데이터를 바꾸면 성능이 오른다는 기대는 근거가 약하다.

**증상.** 사용자가 본 것은 성능이 아니다. 진단은 [23번](23_multi_disease_model_design.md) §1에 있고, 요점만 옮기면 — 규칙 엔진은 4개 질환을 판정하는데 ML은 2개뿐이라 화면 절반이 "모델 없음"으로 비어 있고, 고혈압 모델은 혈압을 입력으로 아예 받지 않는다.

**데이터가 필요한 곳은 따로 있다.** 성능이 아니라 **범위**다. 이상지질혈증·대사증후군·지방간·신기능에 라벨이 없어서 카드를 못 그린다. 이 문서가 답하는 것은 그쪽이다.

## 3. 국내 데이터 — 2026-08-21 재확인

[21번](21_modeling_overview.md) §1의 표를 갱신한다. 각 항목은 공식 페이지를 열어 확인했고, 확인 못 한 것은 그렇게 적었다.

| 데이터 | 절차 | 검사값 | 확인 |
|---|---|---|---|
| **KNHANES 국민건강영양조사** | 회원가입 → 이용계획서 → **3일 이내 승인** → SAS·SPSS 다운로드. **IRB 아님** | 있음 (혈압·혈당·지질·크레아티닌·AST/ALT) | 질병관리청 공지(kdca.go.kr/bbs/kdca/42/309531) 원문. 2024년분 2025-12-31 공개, 변수 약 800개 |
| **한국의료패널 KHP** | 회원가입 + 이용자 준수사항 동의 → 이메일 인증 → **즉시 다운로드**. 심의 없음 | **없음** | 게시판 직접 확인. 1기 2008–2018, 2기 2019–2024, SAS·SPSS·STATA. 주소는 포트가 붙은 `khp.re.kr:444` |
| **고령화연구패널 KLoSA** | 다운로드 전 설문(소속·활용분야) 작성 → 즉시 다운로드. 회원가입도 심의도 없음 | **없음** | 목록 직접 확인. **공개 파동이 검증자마다 갈렸다** — 한쪽은 1~8차(2006–2020), 다른 쪽은 1~10차(2024)까지 봤다고 보고. 사람이 한 번 열어 확정해야 한다 |
| **NHIS 건강검진정보 공개파일** | data.go.kr 파일데이터. 로그인 불필요가 원칙이나 **봇 차단**이라 브라우저로 받아야 한다 | 있음 (혈당·지질·크레아티닌·AST/ALT/γ-GTP) | 데이터셋명 `국민건강보험공단_건강검진정보_20241231`, 연 100만 건. **eGFR은 못 만든다** — 연령이 5세 구간, 신장 5cm 구간이라 CKD-EPI에 넣을 수 없다(`data/load_nhis_checkup.py:147`에 이미 기록됨) |
| **KoGES** | 질병보건통합관리시스템 가입 → 연구자 권한 승인 → 분양 신청. **IRB 승인서 또는 심의면제서** | 있음 (OGTT 포함) | 분양 안내 페이지 원문. 신청자격이 "대학·정부출연/민간 연구기관 연구자"로 제한된다. 21만 명 |
| **지역사회건강조사 KCHS** | 원시자료 요청 → 검토 → 다운로드 | 없음 (자가보고 이환) | 지역 보정용. 라벨원으로는 부적합 |
| **AI-Hub 만성질환·당뇨추적** | 온라인 안심존. 소속 증빙 필요 | 있음 | **부트캠프 수강증이 소속 증빙으로 인정되는지 미확인.** 이게 통과 못 하면 나머지 논의가 무의미하다. 표본 2,109명으로 작기도 하다 |
| **NHIS 표본코호트 2.0 / 맞춤형DB** | 신청 + 심의 + 수수료, 분석센터 | 있음, **종단** | 117만 명 2002–2023. 한국인 + 종단 + 실측 검진값이라 값어치가 가장 크고 문턱도 가장 높다 |
| **HIRA 환자표본자료** | 이용 서약서 제출 확인. IRB 필수 여부 **미확인** | 청구코드 (임상 확진과 다름) | 4종 합계 약 100만 명 |
| **K-CURE** | 심의 | 암 중심 | 이번 범위 밖 |

**두 가지가 확실히 뒤집혔다.**

첫째, KNHANES는 IRB가 아니라 이용계획서다. 승인이 3일 이내다. 그리고 §1이 보였듯 팀이 이미 통과했다.

둘째, KoGES는 **IRB 승인서 또는 심의면제서** 둘 중 하나다. 면제서로도 된다는 뜻이라 [21번](21_modeling_overview.md) §1의 "IRB 승인서 또는 심의 면제서 필수"가 정확한 서술이었다. 실제 관문은 IRB 자체가 아니라 **"대학·연구기관 연구자" 자격 요건**이다. 학교나 지도교수를 통할 수 있는지가 이 항목의 실제 갈림길이다.

**배제 권고 하나.** Mendeley Data에 올라온 KNHANES 2007–2016 미러(DOI 10.17632/jc3rwftjnf.1)는 개인 연구자가 2018년에 올린 것이고 파일 목록·행수를 확인할 수 없었다. 원본이 무료로 열려 있는데 출처 불명 미러를 쓸 이유가 없다.

## 4. 해외 데이터

### 4.1 종단 코호트 — 발병 라벨을 만들 수 있는 것

지금 모델은 유병 선별이고 시안은 "다음 5년"을 약속한다. 그 간극을 메우려면 같은 사람을 두 시점 이상 추적하고 **두 시점에 검사값이 있는** 자료가 필요하다.

| 데이터 | 접근 | 검사값 파동 | 한계 |
|---|---|---|---|
| **CHARLS** (중국) | 회원가입 후 다운로드 | **2011·2015 두 파동만** 공개 assay (HbA1c·FPG·지질·크레아티닌·Cystatin C) | **45세 이상.** 1.7만 명. 27·38세 페르소나를 못 덮는다 |
| HRS (미국) | 등록 후 다운로드 | biomarker 파일 별도 등급 | 51세 이상 |
| ELSA·SHARE·TILDA | 등록 | 파동별 상이 | 유럽 고령자 |
| CHNS (중국) | 즉시 | 파동별 | 영양 중심 |
| MESA·ARIC (BioLINCC) | DUA + 심의 | 있음 | **면제 판정 수용 여부가 연구별로 다르다** — Framingham은 "면제로는 안 된다"고 명시한다. MESA·ARIC 개별 확인 필요 |
| All of Us | 기관 DURA + 신원검증 | 있음 | 보안 워크벤치 안에서만 |
| UK Biobank | 신청 중단 | 있음 | 이번 일정 밖 |
| **NHANES Linked Mortality File** | **즉시** | — | 1999–2018 NHANES에 2019-12-31까지 사망 추적. **'사망'은 '발병'이 아니고** 공개판은 일부 값이 섭동돼 있다 |

CHARLS가 가장 현실적인 후보이고, 그 이유가 성능이 아니라 **구조**다. T0의 혈당을 특징으로 쓰고 T1의 혈당을 라벨로 쓰면 라벨 누출이 정의상 사라진다. 지금 당뇨 모델이 혈당을 못 받는 병리가 통째로 없어진다.

다만 45세 이상 중국 코호트다. 한국 30~40대에 쓰면 외삽이고, 위 표에서 본 대로 국내 코호트끼리도 C가 0.71 → 0.63으로 떨어진다. **이번 학기 노선이 아니라 다음 단계 후보로 둔다.**

### 4.2 즉시 다운로드 — 등록도 심의도 없는 것

| 데이터 | 규모 | 실측 검증 |
|---|---|---|
| **BRFSS 연도별 원본** (CDC) | LLCP2024XPT.zip **83,007,956바이트**, 2025-08-21 게시. 2025년분은 아직 없음 | HEAD 200 확인 |
| UCI 336 CKD / 45 Heart Disease / 296 Diabetes 130-hospitals | 소~중 | 확인 |
| MIMIC-IV Demo / eICU Demo | 소 | 확인. 정식판은 PhysioNet credentialed(CITI 교육 + DUA)로 **무료이고 학생도 취득 가능하다** — "해외 EHR = IRB 벽"은 틀린 서술 |
| WHO STEPS | 국가별 | 신청 필요 |
| IHME GBD | 집계 | 개인 단위 아님 |

BRFSS는 저장소가 이미 채택 보류로 결론 낸 자료다([09번](09_chronic_disease_model_plan.md) §8). 새 후보로 다시 올릴 이유가 없다.

## 5. 데이터가 아니라 공식 — 공개 검증 위험 스코어

이번 조사에서 실무 가치가 가장 큰 갈래다. **학습 데이터 없이 계수만으로 즉시 붙는다.**

| 스코어 | 질환 | 개발 인구 | 성능 | 재현 가능성 |
|---|---|---|---|---|
| **Lee 2012 한국인 당뇨 자가진단 점수** | 당뇨 (미진단 T2DM) | **KNHANES 9,602명 개발 / 8,391명 검증** | 검증 **AUC 0.73**, 컷 ≥5에서 민감도 80% 특이도 53% | **가능.** PMC3402268 오픈액세스. 입력 6개(나이·가족력·고혈압·허리둘레·흡연·음주) 전부 **검사값 없음** |
| **HSI 지방간 지수** | 지방간 | **한국인 검진 10,724명** | AUROC **0.812** | 가능. `8×(ALT/AST) + BMI + 2(여성) + 2(당뇨)`. 배제 <30 / 지방간 >36 |
| FLI 지방간 지수 | 지방간 | 이탈리아 496명 | AUROC 0.84 | 가능. TG·GGT·허리둘레·BMI 필요 |

**세 줄 정리.**

- 당뇨와 지방간은 **한국인 데이터에서 나온 공식**이 있다(Lee 2012, HSI). 해외 스코어보다 이쪽이 근거가 낫다.
- 심뇌혈관은 지금 붙일 수 없다. 성능이 가장 좋은 것은 계수가 없고, 재현 가능한 것은 한국인에게 어긋난다.
- 라이선스에 함정이 있다. Lee 2012 논문에 "educational and not for profit" 재사용 제한이 박혀 있고, KNHANES 계열은 KOGL 제4유형/CC BY-NC로 비상업이다. **배점표 숫자 자체는 사실이라 저작권 대상이 아니라고 볼 여지가 있지만, 상용 전환 시점에 법무 확인이 필요하다.**

## 7. 질환별 라벨 사전

질환을 늘리는 결정은 이 표에서 나온다. **오른쪽 두 열이 핵심이다** — 라벨을 정의하는 검사값은 그 질환의 입력이 될 수 없고, 다 빼고 나서 무엇이 남는지가 ML로 갈지 규칙으로 갈지를 결정한다.

| 질환 | 라벨 정의 | 기준 출처 | 차단해야 할 입력 | 차단 후 남는 것 |
|---|---|---|---|---|
| 당뇨 | FPG≥126 or HbA1c≥6.5 or 진단·투약 | 현행 `labels.py` | FPG, HbA1c, 진단, 투약 | 나이·성별·BMI·주관적건강·생활습관·**혈압** |
| 고혈압 | SBP≥140 or DBP≥90 or 진단·투약 | 현행 `labels.py` | SBP, DBP, 진단, 투약 | 위와 같고 혈압이 빠짐 |
| 고콜레스테롤혈증 | TC≥240 or 지질강하제 | 한국지질·동맥경화학회 5판(2022) | TC, 진단, 투약 | 인구통계·생활습관 |
| 저HDL콜레스테롤혈증 | HDL<40 (남) / <50 (여, 부가분석) | 동상 | HDL, 진단, 투약 | 동상 |
| **대사증후군** | 5요소 중 3개 이상 | NCEP-ATP III 개정(2005). **허리둘레만 대한비만학회 남90/여85** | **허리·TG·HDL·혈압·FPG 전부** | **나이·성별·생활습관뿐 → ML 불가** |
| 비만·복부비만 | BMI 6단계, 허리 남≥90/여≥85 | 대한비만학회 2022 8판 | (예측 대상 아님) | — |
| 지방간 | HSI>36 (배제 <30) | Lee JH 2010, 한국인 10,724명 | ALT·AST·BMI | 거의 없음 → 공식으로 |
| 신기능 저하 의심 | eGFR<60 | CKD-EPI 2021 (Inker 2021) | 크레아티닌 | 거의 없음 → 공식으로 |
| 우울 | PHQ-9 총점 ≥10 | Kroenke·Spitzer | (9문항이 곧 답) | **예측 대상이 아님** |

**이름에 관한 규칙 하나.** 단면 1회 측정으로 만든 신장 라벨을 `label_ckd`로 부르면 안 된다. KDIGO는 eGFR<60이 **3개월 이상 지속**될 것을 요구하는데 NHANES도 KNHANES도 1회 측정이다. `label_egfr_low_single_measure`로 쓰고 화면에는 "신기능 확인 필요"로 표시한다. 유병률이 실제보다 부풀려지는 문제라 문구 취향이 아니다.

**정의가 충돌하는 지점 두 개.** 한쪽으로 고정하지 않으면 한 화면에서 모순이 보인다.

1. **여성 HDL** — 대사증후군 기준은 50, 이상지질혈증 진단 기준은 40이다. 같은 HDL 45가 두 카드에서 다르게 판정된다. 카드마다 어느 기준인지 병기한다.
2. **허리둘레·BMI** — 한국 기준(남90/여85, BMI 25부터 1단계 비만)과 국제 기준(남102/여88, BMI 30부터 비만)이 다르다. NHANES로 학습하면서 한국 절단값으로 표시하면 학습 분포와 표시 기준이 어긋난다. **표시는 한국 기준으로 고정하고 학회명을 병기한다.**

**설문만으로 어디까지 되는지도 확인했다.** CKD를 자가보고 항목만으로 예측하는 SCORED(Bang 2007)는 내부 AUC 0.88이지만 **외부 검증에서 0.71로 떨어진다.** 게다가 입력 절반이 "고혈압·당뇨·심혈관질환 진단받았나"인데 우리 타깃은 아직 진단 안 받은 사람이라, 그 집단에서는 사실상 나이 하나로 굴러간다. **크레아티닌 없이 CKD를 화면에 올리는 건 권하지 않는다.**

한국인 대상으로 검증된 non-lab 이상지질혈증 예측 스코어는 찾지 못했다 — 미확인으로 남긴다.

## 8. 더미·합성 데이터 판정

사용자가 물은 선택지다. 결론부터.

> **정답을 우리가 아는 것은 만들어도 되고, 분포를 우리가 지어내는 것은 만들면 안 된다.**

### 해도 되는 것

| 용도 | 방법 | 진입점 |
|---|---|---|
| **규칙 엔진 임계값 경계 픽스처** | `rules/*.py` 임계값 양옆 값으로 프로필을 손으로 만든다. FPG 99.9/100/125.9/126, HbA1c 5.69/5.7/6.49/6.5, OGTT 139/140/199/200 | 신규 `app/tests/rule_assessment_apis/test_threshold_boundaries.py` |

| API 계약 테스트 프로필 | 현재 방식 그대로. 필요한 건 다양성이 아니라 경계 케이스 | `app/tests/prediction_apis/` |

### 하면 안 되는 것

**SMOTE·ADASYN·오버샘플링으로 소수 클래스를 부풀린다.** 시뮬레이션 연구 두 편이 정면으로 반박한다. van den Goorbergh 외(JAMIA 2022, [10.1093/jamia/ocac093](https://doi.org/10.1093/jamia/ocac093))는 로지스틱 회귀에서 언더/오버샘플링과 SMOTE 셋 다 소수 클래스 확률을 크게 과대추정했고 AUROC는 개선하지 못했으며, 좋아진 민감도·특이도 균형은 **임계값을 옮기는 것만으로 똑같이 얻어졌다**고 보고했다. Carriero 외(Stat Med 2025, [10.1002/sim.10320](https://doi.org/10.1002/sim.10320))는 여러 ML 알고리즘에서 같은 결과를 재현했고, 나아가 **생긴 오보정이 사후 재보정으로 항상 복구되지는 않는다**고 결론지었다. "SMOTE로 늘리고 Platt으로 다시 보정하면 되지 않나"가 통하지 않을 수 있다는 뜻이다.

이 제품에서 특히 나쁘다. `app/services/risk.py`는 Platt 보정된 확률을 내고, 그 확률에서 동년배 백분위·등급 배지·상위 10% 경보가 **전부 파생된다.** 망가지는 것이 정확히 그 확률이다.

**CTGAN·TVAE·synthpop으로 NHANES를 늘려 재학습한다.** 진짜 사람을 두 배 넣어도 안 움직인 지표가 그 사람들의 분포에서 뽑은 가짜 사람으로 움직일 방법이 없다. 그리고 홀드아웃 설계가 먼저 깨진다 — `splits.py`가 2021–2023 주기를 통째로 떼는데, 생성기가 전 주기에서 학습하면 홀드아웃 정보가 학습 쪽으로 샌다.

**한국인 분포를 가정해 더미를 만든다.** 이 프로젝트에서 가장 위험한 선택지다. 한국인 보정이 필요한 이유는 미국 인구의 결합분포가 한국인과 다르기 때문인데, 그 다른 분포를 우리가 지어내면 모델이 배우는 것은 한국인이 아니라 "우리가 한국인이라고 믿는 가정"이다. 결론을 데이터로 검증하는 대신 결론을 데이터에 써넣는 셈이다. **게다가 §1에서 보듯 진짜 KNHANES가 이미 팀 안에 있다.**

**BRFSS 11질환의 낮은 PPV를 오버샘플링으로 해결한다.** 원인이 불균형이 아니다. 뇌졸중은 유병률 3.3%에 특이도 0.695다 — PPV 0.08은 산수의 결과다. 병목은 `choose_threshold`가 쓰는 Youden J이지 표본 구성이 아니다. 오버샘플링을 하면 학습 시점 유병률만 바뀌고 배포 시점 3.3%는 그대로라, PPV는 그대로인데 확률만 부풀어 오른다.

**합성 행을 `unified.csv`에 섞는다.** 지금 이걸 잡는 장치가 파이프라인 어디에도 없다. `build_unified.py:142`의 미등록 출처 검사가 `print`로 알리기만 하고 실패시키지 않는다. **합성을 쓰든 안 쓰든 이 구멍은 막아야 한다.**

| NHIS 건강검진정보 | 이용허락 유형 **미확인** | 미확인 | 브라우저로 확인 필요 |
| Lee 2012 배점표 | "educational and not for profit" | 있음 | 논문 원문에 명시 |
| Jee 2014 (Korean Heart Study) | CC BY-NC 3.0 | 있음 | 확인 |
| QRISK3 | LGPL v3 (ClinRisk Ltd.) | 없음, 카피레프트 | 확인 |
| CRAN `preventr` | MIT | 없음 | v0.12.0, 2026-06-24 |
| CRAN `CVrisk` | GPL-3 | 카피레프트 전파 주의 | 확인 |

| Kaggle 미러 | **미확인** | 미확인 | 3자 재업로드가 원 이용허락을 상속하는지 불명 |

**규칙 하나.** 공개 스코어는 (a) 오픈액세스로 배점표가 열리고 (b) 계수를 자체 구현하는 두 조건을 만족하는 것만 채택한다. GPL 코드는 읽지 말고 논문에서 수치를 다시 확인해 독립 구현한다.

**KNHANES가 비상업이라는 점은 무겁다.** 표시 보정에만 쓰는 것과 서빙 모델의 학습 데이터 자체를 갈아타는 것은 파급이 다르다. 상용 전환 계획이 생기면 그 시점에 전부 다시 봐야 한다.

## 11. 미확인·충돌 — 확정형으로 쓰면 안 되는 것

| 항목 | 상태 |
|---|---|
| KLoSA 공개 파동 | 검증자마다 1~8차(2006–2020)와 1~10차(2024)로 갈렸다. 사람이 열어 확정할 것 |
| KNHANES 검사값 변수명 (`HE_glu`, `HE_chol`, `HE_crea` 등) | **어느 검증에서도 확인되지 않았다.** HN24 명세서에도 검사값 변수가 없다. 이용지침서 대조 필요 |
| KNHANES에 ACR(요알부민/크레아티닌비)이 있는 주기 | 미확인. CKD 2축 중 하나가 불확실 |
| NHIS 건강검진정보의 크레아티닌 존재 | 로더의 기대값이지 파일 실측이 아니다. 있어도 **연령 5세 구간 때문에 eGFR은 못 만든다** |
| KRPM 계수 재현 가능성 | 보충자료 appendix A를 확보하기 전까지 불가 |
| AI-Hub 소속 증빙에 부트캠프 수강증 인정 여부 | 미확인. AI-Hub 3건 전체의 성립 여부를 가르는 단일 관문 |
| BioLINCC의 IRB 면제 수용 여부 | 연구별로 다르다. Framingham은 면제 불가를 명시. MESA·ARIC 개별 확인 필요 |
| KoGES 심의 소요일 | "3~5일" 수치의 1차 출처를 찾지 못했다 |
| 국내 통계의 고혈압 유병 정의가 `labels.py`와 같은지 | **재보정을 하려면 반드시 대조해야 한다.** 정의가 다르면 재보정이 새 편향을 넣는다 |
| KOFRAX 실체 | PubMed 검색 결과 2건. 확정 인용 불가 |
