### Sprint 2 (8/17~8/23)
- 오성민: EC2/Docker 인프라 구축

- 권민재: FastAPI 인증·구독 API, 프론트엔드 로컬 저장 계층과 건강기록 CRUD
- 조현승: 데이터 전처리 및 예측 모델 베이스라인(Logistic Regression) 학습
- 전원: 1순위 기능(서비스 계정·로컬 프로필·로컬 건강기록) 1차 통합

### Sprint 3 (8/24~8/30)
- 오성민: 계정·초대 메타데이터 서버와 로컬 건강정보 보안 경계 검증
- 정다원: 건강 이력·대시보드 그래프와 암호화 백업 UI 연동
- 권민재: 로컬 건강기록·백업 기능 및 가족 초대 API 구현
- 조현승: 모델 성능 개선 실험(지표 2종 비교, MLflow 기록) — 평가기준 3-1

### Sprint 4~5 (8/31~9/13, 기능 고도화)
- 2순위: 초대 수락, 기존 로컬 프로필 연결, 중복 프로필 감지·병합·되돌리기 구현
- 로컬 OCR·예측 기능과 직접 입력 대체 경로 구현
- 3순위: 접근 범위와 선택 데이터 암호화 이전을 구현하고 WebRTC 직접 전송·충돌 처리를 기술검증

- UI 일관성 폴리싱(평가기준 4-2)

> 2·3순위 기능은 제외 기능이 아니다. 앞 단계의 선행조건이 조기에 충족되면 해당 기능을 즉시 앞당겨 구현하고, 지연되더라도 기능명세와 최종 와이어프레임 범위에는 유지한다.
