# ADR-0015: 이어봄 에이전트는 정책·근거 파이프라인 위의 bounded 루프다

## 배경

ADR-0011은 개인화 AI를 인증된 서버가 허용 도구만 호출하는 방식으로 두었다. 현재 챗봇은 서버가 필요한 의료 근거를 먼저 준비하고, 허용 도구를 한 차례만 고르는 제한형 tool calling이다. 반복 루프가 생기면 모델이 권한·근거·원본 서류를 스스로 고르게 되기 쉽다.

가족 건강기록은 서버 정본(ADR-0011)에 있고, 행위자는 가구 세션·위임 PIN·역할(ADR-0012)과 연령 이벤트(ADR-0013)로 가른다. 자율성과 이 인가 경계를 분리해야 한다.

## 결정

- 에이전트는 기존 의료 근거·권한·문서 Vision 파이프라인을 대체하지 않는다.
- 권한·capability 정책이 러너보다 먼저다. 읽기 전용이라도 도구 목록을 열기 전에 계정, 활성 프로필, 가구, 세션 종류, **PIN 행위자·역할·capability**, **미성년·성년 전환 상태**를 검사한다.
- 의료적 주장·건강기록 기반 답변의 필수 근거는 서버가 준비한다. 에이전트는 그 근거를 생략할 수 없다.
- 시설·약품·날씨·추가 기록 조회 등 허용된 추가 행동만 에이전트가 최대 N번 선택한다.
- 질문 분류가 애매하면 의료 질문으로 취급한다.
- 권한은 도구 허용, 프로필·기간·필드 범위, 반환 결과 필터의 세 층이다. 다른 가족 기록이나 전체 기간을 도구가 열려 있다는 이유만으로 반환하지 않는다.
- 건강정보 쓰기는 사용자가 본 초안의 해시에 묶인 단기·1회 승인 토큰만 허용한다. 저장 직전 내용·프로필·권한을 재검증한다.
- 문서 Vision 원본 판독과 에이전트는 분리한다. ADR-0014의 비식별화가 끝나기 전까지 Vision을 대화형 도구로 열지 않는다.
- 에이전트에는 사용자 확정값만, 질문에 필요한 기간·필드만 전달한다.
- Langfuse는 프로덕션에서 메타데이터만 남긴다. 건강수치 원문은 합성 환경에서만 trace에 기록한다. 모델 공급자 마스킹과 관찰 데이터 마스킹은 별개다.
- 픽셀 마스킹은 외부 Vision 전송 전에 끝낸다. 프롬프트로 개인정보를 무시하라고 하는 것은 마스킹이 아니다.

## 검토한 대안

### 읽기 전용 러너를 만든 뒤 권한 게이트를 붙인다

기각. 러너가 도구를 호출하는 순간부터 가족 건강기록(서버 정본)에 닿는다. ADR-0012의 위임은 실행 중 철회될 수 있으므로 매 도구 직전에 다시 검사한다.

### 의료 근거 조회를 전부 에이전트 도구 선택에 맡긴다

기각. 모델이 도구를 건너뛰면 근거 없는 의료 답변이 나온다. ADR-0011의 “서버가 확정한 범위 안에서만 도구가 동작”과 어긋난다.

### 모든 질문에 건강기록과 지식을 무조건 미리 불러온다

기각. 일상 대화·사용법에까지 기록을 읽으면 최소 권한과 비용 한도를 깬다. 애매한 경우만 의료 쪽으로 기울인다.

### 문서 Vision을 에이전트 도구로 즉시 개방한다

기각. `document_id`만 넘겨도 백엔드가 원본을 외부 Vision에 보낸다. ADR-0014의 예외 범위를 넘는다.

### PIN만으로 쓰기 승인을 대신한다

기각. ADR-0012는 PIN을 본인확인·DEK로 쓰지 않는다. 건강정보 쓰기는 초안 해시 승인 토큰과, 필요한 경우 계정 재인증을 쓴다. 성년 전환·삭제·공유 확대는 ADR-0013을 따른다.

## 결과와 감수할 단점

- 에이전트 과제는 잠긴 도구 집합 안에서 다음 행동을 반복 선택하는 일로 좁아진다.
- 분류기 오탐 시 일상 질문에도 근거 준비나 답변 제한이 붙어 지연·거절이 늘 수 있다.
- 결과 단위 필터와 승인 토큰 결속은 도구 래퍼마다 구현 부담이 생긴다.
- 프로덕션 Langfuse만으로는 수치 단위 디버깅이 어렵다. 합성 환경과 메타데이터 canary로 보완한다.

## 재검토 조건

- 로컬 픽셀 마스킹과 사용자 동의 미리보기가 제품 경로에 들어왔을 때
- 위임 철회·프로필 전환·성년 대기를 실행 중 재검사하는 정책 모듈이 코드로 고정됐을 때
- 합성 시나리오 평가에서 근거 누락·권한 우회가 허용 기준을 넘을 때

## 한 문장 요약

> 서버가 필수 근거와 허용 도구를 먼저 확정하고, 에이전트는 ADR-0011·0012·0013이 잠근 범위 안에서 최대 N번 다음 행동을 고른다. 문서 Vision과 건강정보 쓰기는 그 루프 밖에 둔다.
