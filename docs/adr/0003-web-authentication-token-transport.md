# ADR-003: 웹 인증 토큰 전달 방식

- 상태: 승인
- 결정일: 2026-08-18
- 적용 대상: 이어봄 웹 클라이언트와 서비스 API의 인증 경계
- 관련 결정: [ADR-001 웹 기반 로컬 우선 서비스 전환](0001-web-local-first-architecture.md)

## 1. 배경

웹 클라이언트가 장기 인증 수단을 직접 읽을 수 있으면 XSS 발생 시 토큰이 외부로 반출될 수 있다. 반대로 모든 인증을 서버 세션으로 전환하면 브라우저 보안은 단순해지지만, 현재 범위보다 큰 인증 구조 변경이 필요하고 향후 네이티브 앱이나 비브라우저 API 사용 가능성도 함께 제한한다.

현재 목표는 웹 보안을 높이면서도 짧은 수명의 표준 Bearer 인증과 향후 클라이언트 확장 가능성을 유지하는 것이다.

## 2. 결정

- Access Token은 짧은 수명의 JWT Bearer Token으로 사용하고 브라우저 메모리에만 둔다.
- Refresh Token은 JavaScript에 노출하지 않고 `Secure`, `HttpOnly`, `SameSite`가 적용된 쿠키로만 전달한다.
- Refresh Token은 사용할 때마다 회전하며, 재사용이 탐지되면 같은 세션 계열을 폐기한다.
- 쿠키가 자동 전송되는 인증 요청은 허용된 Origin을 확인한다.
- 브라우저의 영구 저장소에는 Access Token과 Refresh Token을 저장하지 않는다.

## 3. 검토한 대안

### 3.1 Refresh Token을 JSON으로 반환

기각한다. 프론트엔드 구현은 단순하지만 브라우저 JavaScript가 장기 인증 수단을 소유하게 된다. 이를 영구 저장소에 보관하면 한 번의 XSS로 세션이 외부에 반출될 수 있고, 저장하지 않으면 새로고침 후 인증 유지가 불안정하다. 건강정보 서비스에서 감수할 이유가 없는 위험이다.

### 3.2 Redis 기반 불투명 세션과 BFF로 전면 전환

보류한다. 브라우저에 토큰을 노출하지 않는 장점이 있지만 인증 경계를 전면 변경하고 웹 전용 서버 결합을 높인다. 웹 전용 제품이 장기 방향으로 확정되지 않은 현재에는 변경 범위에 비해 추가 이점이 제한적이다. 검토 없이 즉시 전환하면 네이티브 앱과 외부 API가 필요해질 때 별도 인증 체계를 다시 만들어야 한다.

### 3.3 Access Token과 Refresh Token을 모두 쿠키로 전달

기각한다. 브라우저 토큰 관리는 단순해지지만 모든 상태 변경 API가 쿠키 자동 전송과 CSRF 방어에 의존한다. Bearer 인증을 사용하는 비브라우저 클라이언트와의 호환성도 낮아진다.

### 3.4 장기 Access Token만 사용

기각한다. 갱신 구조는 단순해지지만 토큰 탈취 시 노출 기간이 길고 세션 단위 회전과 재사용 탐지가 불가능하다.

## 4. 결과와 감수할 단점

- 장기 인증 수단을 JavaScript에서 분리하면서 표준 Bearer API를 유지한다.
- Access Token이 유출되면 짧은 만료 시간까지 사용할 수 있으므로 수명을 짧게 유지해야 한다.
- 쿠키 기반 갱신에는 CSRF와 허용 Origin 검증이 필요하다.
- 여러 탭의 동시 갱신 경쟁을 클라이언트가 조정해야 한다.
- 브라우저 새로고침 후에는 Refresh Token 쿠키로 새 Access Token을 발급받아야 한다.

## 5. 재검토 조건

다음 조건 중 하나가 충족되면 기존 ADR을 수정하지 않고 새 ADR에서 불투명 세션/BFF 또는 다른 인증 구조를 다시 평가한다.

- 이어봄이 장기적으로 웹 전용 제품임이 확정된다.
- 내부 서비스가 분리되어 브라우저 전용 API 중계 계층이 필요해진다.
- Access Token을 브라우저에 노출하지 않아야 하는 규제·보안 요구가 생긴다.
- 네이티브 앱이나 외부 API 지원이 확정되어 웹과 비브라우저 인증을 함께 설계해야 한다.
- 현재 토큰 회전 방식에서 반복적인 동시 갱신·운영 문제가 확인된다.

## 6. 한 문장 요약

> 짧은 Access JWT는 Bearer로 유지하고, 장기 Refresh Token만 보호된 쿠키로 격리하며, 전면 BFF 전환은 웹 전용 방향이 확정될 때 다시 결정한다.
